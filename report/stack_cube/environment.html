🟩 Stack Cube — Environment & Physics Settings

Franka FR3 + Two Cubes Stacking | MSRA Collaboration WIP

1. Task Description

Franka FR3 로봇이 흰색 큐브를 집어서 초록색 큐브 위에 쌓는 stacking task.

  • Goal: 흰색 큐브(White)를 집어서 초록색 큐브(Green) 위에 쌓기
  • Success condition: white cube z ≈ 0.06 (green 위), |z_err| < 15mm, xy_err < 20mm
  • Max episode steps: ~400 steps (avg episode length from data)
  • Collaboration: MSRA (Microsoft Research Asia) 공동 연구

Finger kpTBD (replay only)PnP: 5000
⚠ CRITICAL: Gripper normalization 불일치.
Stack 데이터셋은 raw meter 값 (0.02~0.04)으로 gripper_width 저장. PnP는 normalized (0~1). GR00T processor는 normalization 없음 (mean_std_embedding_keys=null), 따라서 Stack GR00T 모델은 ~0.02–0.04 스케일의 action을 출력함.

→ Stack RL env에서 gripper를 정규화하면 안 됨. Raw meter 그대로 사용해야 함.

5. Replay Pipeline (3-Phase)

Stack의 데이터 수집은 CSV → MuJoCo replay → LeRobot dataset 파이프라인을 사용:

Phase 1: Pre-Grasp (Kinematic)

  • IK로 로봇을 grasp 시작점까지 이동
  • 큐브는 테이블 위 정적 위치
  • Kinematic mode (mj_forward)

Phase 2: Grasp (Rigid Attach)

  • 큐브를 TCP에 rigid attach
  • 로봇이 큐브를 들고 이동
  • Kinematic + 큐브 위치 강제 업데이트

Phase 3: Release (Physics)

  • Green cube 위에서 gripper open
  • 실제 물리 시뮬레이션으로 전환 (mj_step)
  • N_SETTLE = 30 steps 동안 안정화 대기
