Key Findings

1. Q Saturation is the Primary Failure Mode

With γ=0.99, Q values converge to Qmax=10.0 ceiling within ~20k steps. The actor receives vanishing gradient signal because Q values are compressed near the ceiling. Lowering γ to 0.95 reduces the Q range to ~1.9 (well below Qmax=10), restoring healthy gradient flow.

2. L2 Regularization Sweet Spot: L2=5.0

Consistent with PnP experiments:

L2Effect (Stack)PnP Reference
0.01–0.1Residual too large when combined with high action_scaleL2=0.1 hurts good trajectories
1.0Baseline config. Residual shrinks to ~0 over training"Weak" — below optimal
3.0Better than 1.0, but still below L2=5Good but not best multi-seed
5.0Best SR (80% peak, 64.8% avg10)Best multi-seed (73.3% ± 9.4%)
≥10Not testedKills residual entirely (res→0)

3. Action Scale Must Stay Small (0.1)

Increasing action_scale from 0.1 to 0.3/0.5/1.0 catastrophically destroys performance. The residual becomes too large and overrides the base policy's learned behavior. All three scale-up experiments collapsed to SR <30% within 10k steps.

Final Conclusion

Stack Cube Residual RL: Moderate Success, Diminishing Returns
Best config (L2=5.0, γ=0.95) achieves ~63-65% average SR on hard difficulty (base: 57%) — a real but modest +6-8%p improvement. Peak SR of 80-82% confirms the potential but high variance makes it unreliable.

Why is the Residual Policy Robust?

Architecture Recap: Residual actor input = observation.state (10D: tcp_pos + eef_quat + grip + contact) + observation.object_state (10D: cubes pos/quat) = 20D → MLP [256×3] → 7D residual action.
Noise는 object_state 10D에만 주입. Robot state 10D는 항상 clean.

Robustness 원인 분석 (3가지 요인):

  1. Robot state가 충분히 informative: tcp_pos, grip, contact 등 로봇 자체 상태만으로도 "지금 뭘 해야 하는지" 추론 가능. 특히 grasp 이후 lift/place 단계에서는 robot state가 task completion에 지배적.
  2. Residual output이 bounded: action_scale=0.1 + tanh 활성화로 출력 자체가 매우 작은 correction. 입력 perturbation이 MLP를 통과해도 출력 변화가 제한적 (Lipschitz continuity).
  3. Noisy but still informative: σ=0.02 (20mm) noise는 큐브 위치를 약간 흔들지만 대략적 위치/방향은 보존됨. MLP이 이 정도 variation에서도 올바른 방향의 correction 생성 가능.

핵심: "residual이 0으로 collapse → base만 실행" 되는 것도 아니고, "object_state를 무시하고 robot state만으로 행동" 하는 것도 아님. 작은 perturbation에 대해 MLP 출력이 연속적으로(smoothly) 변하기 때문에 robust한 것. σ=0.05+ (5cm)에서는 object_state가 misleading information이 되면서 성능 하락 시작.

Interpretation:

  • Object pose estimation 오차 20mm 이내에서는 성능 유지 → sim-to-real gap에 대한 긍정적 신호
  • 50mm 이상은 물리적으로 큐브 크기(~40mm)와 비슷한 수준 → 성능 하락 당연
  • Quaternion noise는 0.1× scaling으로 작게 줌 — orientation보다 position이 critical
