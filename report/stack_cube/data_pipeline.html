4. Gripper Width Analysis

Stack gripper_width (raw meters):
  min  = 0.0197  (~2.0cm, fully closed)
  max  = 0.0398  (~4.0cm, fully open)
  mean = 0.0287

PnP gripper_width (normalized 0-1):
  min  = 0.4885
  max  = 0.9959
  mean = 0.7356
⚠ Stack gripper는 정규화되지 않음.
GR00T processor에 mean_std_embedding_keys: null 이므로 모델은 raw 스케일 그대로 학습됨. RL env에서도 반드시 raw meter 값 사용.

5. Replay Pipeline Details

Input: CSV Files

  • 디렉토리: stack_cube*/ 패턴으로 검색
  • 각 episode = CSV 파일 (timestamp, eef_pos, eef_quat, gripper_width)

Processing: 3-Phase MuJoCo Replay

PhaseModeDescription
Pre-graspKinematic (IK)로봇을 grasp 시작점까지 이동, 큐브 테이블 위
GraspKinematic + attach큐브를 TCP에 rigid attach, 로봇이 들고 이동
ReleasePhysics (mj_step)Green cube 위에서 release, N_SETTLE=30 steps 안정화

Key Parameters

CUBE_HALF = 0.02                    # 4cm cube (half-size)
GRIPPER_CLOSE_THRESHOLD = 0.028     # Raw meters
N_SETTLE = 30                       # Physics settle steps after release
SKIP_FRAMES = 20                    # MuJoCo substeps per frame

Output: LeRobot v2.1 Dataset

  • Parquet files: data/chunk-000/episode_NNNNNN.parquet
  • Videos: videos/chunk-000/{cam_base,cam_wrist}/episode_NNNNNN.mp4
  • Meta: meta/info.json, meta/episodes.jsonl, meta/tasks.jsonl
