🟥 Pick-and-Place — Environment & Physics Settings

Franka FR3 + Cube → Bowl | Physics-Based MuJoCo Simulation

1. Task Description

Franka FR3 로봇이 테이블 위의 큐브를 집어서 보울(bowl)에 놓는 pick-and-place task.

  • Goal: 큐브를 grasping → lifting → bowl 위에 placing
  • Success condition: cube가 bowl 안에 안착 (거리 < 9.5cm, 속도 < 0.05m/s)
  • Max episode steps: 500 steps (25s at 20Hz)
  • Cube positions: 64개 고정 위치 (cube + bowl 쌍)
  • Difficulty levels: normal (±2cm, ±15°), hard (±5cm, ±45°)

8. Reward Design (dense_v3)

현재 사용 중인 dense_v3 reward:

# Phase 1: Approach (0.0 – 0.2)
r_approach = 0.2 * (1 - tanh(5 * tcp_cube_dist))

# Phase 2: Grasp (0.2 – 0.4)
r_grasp = 0.2 * is_grasped

# Phase 3: Lift (0.4 – 0.6)
r_lift = 0.2 * clip(cube_z / target_z, 0, 1)

# Phase 4: Transport (0.6 – 0.8)
r_transport = 0.2 * (1 - tanh(5 * cube_bowl_dist))

# Phase 5: Place (0.8 – 1.0)
r_place = 0.2 * is_placed_and_settled

Total: r = r_approach + r_grasp + r_lift + r_transport + r_place  ∈ [0, 1]
