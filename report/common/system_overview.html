1. Overview

Goal: Isaac Sim 기반 residual RL (TD3) 학습 파이프라인을 MuJoCo로 이식하여 훨씬 가벼운 환경에서 동일 알고리즘 실행. GR00T base policy + residual RL agent로 Franka FR3 cube-lift 태스크 학습.

Reference: residual-offpolicy-rl_v1의 v31a 실험 (asymmetric critic, dense_clipped reward, success rate 0.75 in IsaacLab)

2. 구현 완료 항목

2.1 Core Environment — mujoco_vec_env.py

기능상태설명
N개 병렬 환경완료N개 독립 MjModel/MjData 관리
IK Solver완료Damped least-squares + null-space bias, max_iter=50
RGB 렌더링완료front/cam_base/cam_wrist → 84×84 uint8 + 640×360 hires
Depth 렌더링완료observation.depth.front/wrist (1,84,84) float32 [0,1] normalized
34D State완료dof_pos(9) + dof_vel(9) + cogact_ref(7) + contact(3) + ee_xyzrpy(6)
Object State완료observation.object_state (7D: pos3 + quat_wxyz4)
Kinematic Grasp완료Gripper width threshold → T_cube_in_tcp rigid attach
Sparse Reward완료lift ≥ threshold → 1.0
Dense Clipped Reward완료distance(0.1) + contact(0.2) + height(0.5) + success(1.0), clamped [0,1]
Success Termination완료grasped + lift ≥ 4cm → terminated=True
Depth Normalization완료front: [0.554, 1.495], wrist: [0.056, 0.711] per-camera clamp
Persistent Renderers완료5개/env (RGB×3 + Depth×2), 매 step 재생성 방지

2.4 Training Script — train_residual_td3_mujoco.py

기능상태설명
Warmup Collection완료base policy + noise로 buffer 채우기
Critic Warmup완료critic-only updates before actor
TD3 Training Loop완료collect → update → eval 반복
Asymmetric Critic완료--asymmetric_critic → actor=state-only, critic=depth
Multi-Update완료--num_updates_per_iteration 4 gradient updates per step
Offline Buffer (구조)완료buffer 생성 + hybrid batch sampling 코드 존재
W&B Logging완료episode return, success rate, critic loss, buffer size 등
Checkpointing완료best success rate + final checkpoint 저장
Evaluation완료greedy policy (stddev=0) 주기적 eval

7. 앞으로 해야 할 것

7.1 즉시 실행 가능 (코드 완성)

항목우선순위설명
RL 학습 실행 HIGH SLURM 스크립트 작성 → B200에서 train_residual_td3_mujoco.py --asymmetric_critic 실행. 현재 코드로 바로 돌릴 수 있음. wandb 로깅도 지원.
Perturbation 10-env 동시 학습 HIGH --num_envs 10 + perturbation table 적용. 현재 env는 1개 cube 위치만 지원 → perturbation table loader 추가 필요 (cube_positions를 table에서 읽도록).

7.2 기능 보완 필요

항목우선순위설명난이도
Offline Buffer Population MEDIUM CSV 또는 LeRobot 데이터셋에서 (obs, action, reward, next_obs, done) 로드. 현재 offline_rb 구조는 있지만 데이터 로딩 미구현 (TODO 표시). ~2h
Perturbation Table Loader MEDIUM JSON perturbation table → cube_positions 변환. 학습 시 env별 서로 다른 cube 위치 지원. ~1h
Episode 자동 리셋 개선 MEDIUM 현재 terminated 후 auto-reset 미적용 (terminal obs 반환 후 다음 step에서 수동 reset 필요). Training loop에서 done 시 자동 재시작 추가. ~1h
Eval per-env async LOW IsaacLab의 AsyncEvaluator 패턴 → 학습 중 별도 프로세스에서 eval. 현재는 inline eval (학습 일시 중단). ~4h

7.3 성능 개선 방향

항목설명
Grasp Detection 개선 현재: gripper_width < 0.5 → grasped. IsaacLab에서는 contact force > 0.1N. MuJoCo kinematic 모드에서는 물리 접촉이 없어 grasp 조건이 약함 → 중심 외 위치에서 grasp 실패. 개선안: TCP-cube 거리 기반 grasp 판정 (TCP < 2cm from cube + gripper closing)
Physics Mode 전환 현재: kinematic (mj_forward). 향후: physics (mj_step) + cube freejoint. 물리 기반 그래스핑은 더 현실적이나 쿠브 탈출 등 불안정 가능.
Multi-env GR00T Batching 현재: 순자적 per-env inference. GR00T가 batch inference 지원 시 속도 향상 가능 (0.7s/step → ~0.1s/step).
Depth Normalization 재계산 현재 depth norm은 IsaacLab rollout 기반. MuJoCo 카메라 특성이 다를 수 있으므로 MuJoCo rollout으로 재계산 권장.

8.1 학습 커맨드 (v31a 재현)

source ~/.venvs/groot/bin/activate
MUJOCO_GL=egl LD_LIBRARY_PATH=~/.local/lib/gl:${LD_LIBRARY_PATH:-} \
python3 resfit/rl_finetuning/scripts/train_residual_td3_mujoco.py \
    --groot_checkpoint ~/DATA/INTERN/training/gr00t_groot_v2/checkpoint-30000 \
    --scene_xml ~/Repos/Intern/residual-offpolicy-rl_v1/mujoco_menagerie/franka_fr3/fr3_with_hand.xml \
    --asymmetric_critic \
    --actor_hidden_dim 512 --critic_hidden_dim 1024 \
    --actor_lr 1e-5 --action_scale 0.1 \
    --reward_type dense_clipped --success_threshold 0.03 \
    --total_timesteps 50000 \
    --batch_size 256 --buffer_size 200000 \
    --learning_starts 1000 --critic_warmup_steps 500 \
    --num_updates_per_iteration 4 --update_every_n_steps 1 \
    --stddev_max 0.05 --stddev_min 0.05 \
    --eval_interval 5000 --eval_num_episodes 5 \
    --wandb_mode online --wandb_project mujoco-franka-residual-td3
