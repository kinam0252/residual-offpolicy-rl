06. ACT Base Policy + Residual RL 계획

현재 GR00T VLA를 base policy로 사용하는 residual RL 프레임워크에, ACT(Action Chunking with Transformers)를 base policy로 교체/추가하여 residual RL을 학습하는 추후 구현 계획입니다.

1. Action Space 분석

1.1 ACT vs GR00T 출력 비교

ACT (LeRobot)GR00T (Isaac-GR00T)
출력 차원8D8D
표현Absolute EE PoseAbsolute EE Pose
Position (0:3)Absolute xyzAbsolute xyz
Orientation (3:7)Quaternion (xyzw)Quaternion (xyzw)
Gripper (7)Absolute widthAbsolute width
Action Chunk20-step16-step
Config 근거LeRobot 기본 (absolute pose 학습)fr3_lift_config.py: ActionRepresentation.ABSOLUTE
핵심: 둘 다 "다음 N스텝의 절대 TCP 포즈"를 예측하도록 학습됨. Action space가 완전히 동일(8D absolute pose)하여 base policy 교체가 구조적으로 가능.

1.2 데이터셋 검증

ACT 학습에 사용된 LeRobot 데이터셋(Lift_sim_lerobot, Lift_100ep_real 등)을 직접 확인한 결과:

action[t] == state[t+1]   (max_diff = 0.000000)  ← 완벽 일치
action[t] ≠ state[t+1] - state[t]               ← delta와는 불일치

→ ACT는 absolute pose를 예측하며, replay_all_worker.py의 7D normalized delta는 residual RL용 offline 데이터로 별개.

1.3 현재 Residual Action Space

구성요소차원범위스케일결합 방식
Position delta3D[-1, 1]×0.02mbase_pos + residual
Euler delta3D[-1, 1]×0.05radbase_quat ⊗ euler2quat(residual)
Gripper delta1D[-1, 1]×0.1clip(base_grip + residual, 0, 1)

Residual policy는 7D delta를 출력 → wrapper의 _combine_actions()에서 base의 8D absolute와 합성.

2. 구현 계획

2.1 아키텍처

현재 (GR00T base)
GR00T VLA (8D abs, 16-step chunk) → open-loop 실행 → residual RL (7D delta) 합성
↓ 교체
목표 (ACT base)
ACT (8D abs, 20-step chunk) → open-loop 실행 → residual RL (7D delta) 합성

GR00T과 ACT의 action space가 동일하므로, wrapper에서 base policy 모듈만 교체하면 됩니다:

# mujoco_residual_wrapper_pnp.py 수정 개념
class MuJoCoResidualWrapperPnP:
    def __init__(self, ..., base_policy_type="groot"):
        if base_policy_type == "groot":
            self.base_policy = GR00TPolicy(...)     # 기존
            self.open_loop_horizon = 16
        elif base_policy_type == "act":
            self.base_policy = ACTPolicy(...)        # 추가
            self.open_loop_horizon = 20              # chunk_size=20

2.2 구현 단계

단계작업설명
1 ACT 추론 래퍼 작성 LeRobot ACT 체크포인트를 로드하고, GR00T과 동일한 인터페이스(get_action(obs) → 8D×N)로 action chunk 반환하는 래퍼 작성
2 Wrapper 확장 mujoco_residual_wrapper_pnp.py에 base_policy_type 옵션 추가. ACT일 때 open_loop_horizon=20, 관측 전처리 조정
3 Offline 데이터 수집 (ACT base) ACT를 base policy로 zero-residual rollout하여 오프라인 transition 수집. 기존 collect_offline_data_pnp.py 재활용
4 Residual TD3 학습 기존 train_residual_td3_mujoco_pnp.py로 학습. base policy만 ACT로 교체, 나머지 RL 파이프라인 동일
5 평가 및 비교 동일 task/position에서 GR00T+residual vs ACT+residual 성능 비교

2.3 주요 고려사항

Open-loop horizon 차이: GR00T=16, ACT=20. Residual RL이 매 step 개입하는 빈도가 달라짐. ACT의 n_action_steps를 16으로 맞추는 것도 고려.
관측 공간: GR00T은 비전(wrist+base 카메라) 입력을 사용. ACT도 비전 입력이 필요한지, low-dim만으로 충분한지 확인 필요. ACT 학습 시 사용한 관측 modality에 따라 wrapper의 obs 전처리가 달라짐.
추론 속도: GR00T은 B200 GPU에서 batch inference. ACT은 상대적으로 경량 모델이므로 추론 속도가 빠를 수 있음 → open-loop 없이 매 step ACT 호출도 가능할 수 있음.

추후 실험 계획:
  • 동일 PnP hard 환경에서 ACT base + residual TD3 학습
  • ACT base의 zero-residual SR을 먼저 측정하여 baseline 확인
  • GR00T+residual 대비 수렴 속도, 최종 성능, 안정성 비교
  • ACT의 빠른 추론을 활용하여 open-loop 없이 매 step residual 적용 실험
